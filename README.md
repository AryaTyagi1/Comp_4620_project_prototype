# Public Space Information Center (COMP 4020 G5)

> **Status: Prototyping** — This repository contains early-stage design exploration and proof-of-concept work. Structure, APIs, and features are subject to change without notice.

## 📌 Project Overview
A human-computer interaction (HCI) prototype for a **Public Space Information Center**. The goal is to help users (e.g., students, staff) efficiently discover, evaluate, and decide on available public spaces — such as study spots between classes, group meeting rooms, or general seating areas — by surfacing relevant, trustable information.

This milestone (M2) focuses on **field study validation, requirements definition, and design alternatives** rather than a fully functional production app.

## 🧭 Design Alternatives
Three interaction concepts are being explored in this prototype phase:

| # | Alternative | Core Idea |
|---|-------------|-----------|
| 1 | **Map-First Explorer** | Spatial, map-driven discovery of spaces. |
| 2 | **List-First Recommender** | Ranked list of spaces based on user preferences and context. |
| 3 | **Hybrid Dashboard with Push Alerts** | Combined map/list view with proactive notifications. |

*(See `docs/` or the M2 report for sketches and evaluation notes.)*
